# Smart Gift Finder Topical Map Planner

## Purpose

Plan controlled SEO expansion without duplicate or thin pages.

## Pillars

1. Gifts by Recipient
2. Gifts by Budget
3. Gifts by Occasion
4. Gifts by Interest
5. Problem/Situation Gifts

## Process

1. Identify target keyword and search intent.
2. Map keyword to existing page, page needing upgrade, future page, or defer.
3. Check product coverage.
4. Check uniqueness vs existing pages.
5. Define internal links.
6. Define Pinterest/distribution angle.
7. Recommend priority: P1/P2/P3/defer.

## Page Creation Gate

Do not create/publish a page unless it has:

- clear unique intent
- 8+ relevant products where product-driven
- unique title/meta/H1
- direct answer in first 50 words
- affiliate disclosure if product links appear
- internal links
- schema/FAQ where appropriate
- validation plan

## Avoid

- mass programmatic pages
- duplicate recipient/budget pages
- AI-humanized filler
- publishing because a keyword exists without product coverage

## Output

Return:
- Summary
- Files inspected/changed
- P0/P1 blockers
- P2/P3 follow-ups
- Validation commands run
- Validation results
- Safe to commit?
- Safe to push?
- Recommended next action
