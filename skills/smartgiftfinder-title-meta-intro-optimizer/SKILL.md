# Smart Gift Finder Title, Meta, and Intro Optimizer

## Purpose

Make SEO pages distinct, benefit-driven, and easier for Google and users to understand.

## Formula

Use when appropriate:

```text
Target Keyword | Gift-Buyer Benefit | Smart Gift Finder
```

Examples:

```text
Last-Minute Gifts | Thoughtful Ideas That Don’t Feel Rushed | Smart Gift Finder
Gifts for Students | Useful Picks for School, Dorms & Daily Life | Smart Gift Finder
Tech Gifts | Useful Gadgets That Feel Premium | Smart Gift Finder
Gifts Under $50 | Thoughtful Picks That Feel More Expensive | Smart Gift Finder
```

## Process

1. Audit title, meta description, H1, and first 50 words.
2. Flag generic, duplicate, missing-benefit, weak-CTR, or weak-intent copy.
3. Rewrite only scoped metadata/copy.
4. Keep copy natural and not clickbait.
5. Preserve affiliate disclosures and product logic.
6. Do not invent reviews, ratings, delivery claims, prices, or product facts.

## First 50 Words Rule

Every important guide/blog page should answer the query directly in the first 50 words.

## Validation

```bash
npm run typecheck
npm run build
npm run validate:seo-pages
```
