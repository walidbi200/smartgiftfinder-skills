# Smart Gift Finder Pinterest Distribution Planner

## Purpose

Turn approved Smart Gift Finder pages into safe Pinterest traffic without spam or direct merchant bypass.

## Rules

- Send traffic to Smart Gift Finder pages first, not directly to Amazon or merchants.
- Use UTM tracking.
- Start with 3–5 pins/day.
- Do not publish duplicate, misleading, or low-quality pins.
- Do not use fake product images/logos/claims.
- Use only approved/indexable destination pages.

## Required Fields

```text
Keyword
Pin Title
Pin Description
Pin IMG
Post_url
Board
Status
UTM Campaign
Pin Variant
Published At
Notes
```

## Boards

- Gifts Under $50
- Last-Minute Gifts
- Tech Gifts
- Gifts for Students
- Gifts for Boyfriend
- Gifts for Girlfriend
- Gifts for Mom
- Gifts for Dad
- Holiday Gift Ideas
- Cozy Gift Ideas

## Process

1. Select approved guide/blog page.
2. Create 3–5 pin variants.
3. Add UTM URL.
4. Map to a relevant board.
5. Publish slowly.
6. Track impressions, outbound clicks, guide views, affiliate clicks, and email signups.
7. Scale only winners.
