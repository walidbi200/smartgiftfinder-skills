# Smart Gift Finder skills

Independent agent guidance for Smart Gift Finder. This repository is intentionally separate from the website repository.

`AGENTS.md` defines project rules; `skills/` holds the current guidance and `install-skills.sh` installs it. Review the script and destination before running it. No credentials or application runtime are needed. The existing remote main preserves the earlier top-level skill layout; the 2026-10-23 safety branch backs up this workstation's layout without replacing remote main.
